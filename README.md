## 🎯 Core Project Objectives & Engineering Vision
* **The Critical Imperative (Why This Project Matters):** The Gamo/Gofa Zone mass-wasting events of March 2026 resulted in a tragic loss of over 229 lives following prolonged extreme precipitation. In mountain regions with steep slopes, climate change (global warming indicators passing ~1.2°C) makes intense rainfall anomalies more frequent. This project establishes an independent engineering framework to identify land failure hazards *before* structural soil collapse occurs.
* **The Main Technical Innovation:** Standard optical satellites cannot see ground changes during severe storms due to thick tropical cloud decks. This system bridges that gap by fusing NASA radar topography models (**SRTM DEM**) and climate precipitation engines (**CHIRPS**) with cloud-penetrating synthetic aperture radar (**Sentinel-1 SAR**) grids. By exporting spatial pixel arrays directly into local laptop environments, we remove the guesswork and prove the exact physical causes of landscape destabilization with high mathematical precision.

## 🛠️ Remote Sensing Sensors & GEE Elements Ingested
* **Topography Vector Engine:** Shuttle Radar Topography Mission (SRTM) Global 30-meter Digital Elevation Model grid.
* **Climate Atmospheric Tracker:** Climate Hazards Group InfraRed Precipitation with Station data (CHIRPS) daily accumulated rain metric.
* **Cloud-Penetrating Structural Matrix:** Copernicus Sentinel-1 C-band Synthetic Aperture Radar (SAR) Ground Range Detected (GRD) sensor operating in VV polarization look-angles.
* **Core Built-in Cloud Algorithms:** `ee.Terrain.slope()`, `ee.Reducer.sum()`, `ee.Image.cat()`, `FeatureCollection.reduceRegions()`.

## 📊 Scientific Data Graph Diagnostics Visual Legend Guide

Our high-contrast analysis plot, generated inside RStudio and preserved as a 300-DPI high-density picture asset (`gofa_high_contrast_hazard_plot.png`), maps three separate structural dimensions of the landslide site simultaneously:
* **Horizontal Axis (X-Axis Incline):** Hillside Slope Gradient measured from 0 degrees (flat valley ground floor zones) up to high-gravity risk mountain cliffs exceeding 40 degrees.
* **Vertical Axis (Y-Axis Rain Volume):** Accumulated Saturation Volume tracking the seasonal storm envelope from a baseline of 480 mm up to extreme peak cloudburst levels crossing **640 mm**.
* **High-Contrast Hazard Elevation Color Gradient Key:**
  * ⬛ **Solid Black Points:** Low-altitude inundation accumulation basins and river valleys (1,000 to 1,350 meters above sea level). These zones collect runoff but are safe from mass movement gravity shifts.
  * 🟨 **Bright Yellow Points:** Mid-altitude mountainsides and structural friction zones (1,400 to 1,900 meters above sea level) where agricultural soil binding resistance is unstable.
  * 🟥 **Bright Red Points:** Critical mountainous peak ridges and source fracture spines (2,000 to 2,600+ meters above sea level). This is the primary hazard zone where the structural failures triggered the mass slide down the valley.
* **The Bold Blue Model Line ($\color{blue}{\text{---}}$):** This is the calculated linear regression trend line. Its upward angle visually demonstrates that maximum rainfall volume heavily overloaded the steep high-altitude red slopes, completely stripping the landscape of shear friction stability.

## 🚀 Re-execution & Scientific Reproduction Guidelines

### Phase 1: Google Earth Engine Cloud Extraction Pipeline
1. Open your browser and launch the web interface of the **Google Earth Engine Code Editor**.
2. Paste the script file contents located inside `src_gee/gofa_landslide_pipeline.js` into the central console window box.
3. Click the green **Run** action button to view the distributed map sub-panels on the left and right margins of the viewport frame.
4. Navigate to the right-hand utility pane window, find the pending yellow **Tasks** prompt column line, click run, and export the generated 500-point continuous cell array table spreadsheet directly onto your personal Google Drive storage bucket.

### Phase 2: Local Laptop RStudio Ingestion & Plot Processing
1. Download the finished table `.csv` file out of your Drive onto your laptop storage disk directory folder path.
2. Launch **RStudio** and open the script template text rows located within `src_r/gofa_landslide_analytics.R`.
3. Highlight all text elements and press `Ctrl + Enter`. RStudio will prompt an interactive Windows file selection window overlay on your screen dashboard pane.
4. Double-click the downloaded CSV data spreadsheet table using your mouse cursor. The engine will read all 500 rows, evaluate the altitude parameters, draw your customized red-black-yellow hazard chart inside your right-hand **Plots tab viewer panel**, and automatically downlad a sharp `.png` copy to your machine hard disk workspace.
